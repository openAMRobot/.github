# OpenAMRobot Code of Conduct

## Purpose

OpenAMRobot is committed to creating an open, respectful, collaborative, and inclusive environment for contributors, researchers, students, educators, developers, and community members.

This Code of Conduct defines expected behavior within the OpenAMRobot ecosystem.

---

# Expected Behavior

Participants are expected to:

- communicate respectfully
- encourage constructive collaboration
- support learning and education
- provide helpful feedback
- respect different perspectives and experience levels
- focus on technical and community improvement
- behave professionally in public discussions

---

# Unacceptable Behavior

The following behavior is not acceptable:

- harassment
- personal attacks
- discriminatory behavior
- intimidation
- trolling
- deliberate disruption
- deceptive representation
- abusive language
- publishing private information without permission
- intentionally harmful or unsafe technical contributions

---

# Technical Responsibility

Because OpenAMRobot involves robotics, electronics, and autonomous systems, contributors are expected to:

- avoid intentionally unsafe contributions
- communicate safety limitations clearly
- avoid misleading technical claims
- support responsible engineering practices

---

# Collaboration Principles

The community encourages:

- openness
- transparency
- respectful disagreement
- knowledge sharing
- mentorship
- experimentation
- educational accessibility

---

# Enforcement

Organization maintainers and repository maintainers may take reasonable actions in response to unacceptable behavior, including:

- warnings
- comment moderation
- removal of content
- temporary restrictions
- permanent bans in severe cases

---

# Scope

This Code of Conduct applies to:

- GitHub repositories
- discussions
- issues
- pull requests
- documentation collaboration
- community communication channels
- organization-managed events

---

# Reporting Issues

If you experience or observe unacceptable behavior, report it to repository maintainers or organization maintainers through appropriate communication channels.

---

# Good Faith

The goal of this Code of Conduct is to support healthy collaboration, not to discourage technical discussion or constructive criticism.

Respectful technical disagreement is welcome.

---

# Policy Updates

This document may evolve as the ecosystem grows.
