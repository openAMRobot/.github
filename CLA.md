# OpenAMRobot Contributor Agreement Process

Botshare LTD requires a contributor agreement before accepting an external contribution.

## Which agreement applies?

- Use the [Individual Contributor Agreement](INDIVIDUAL_CONTRIBUTOR_AGREEMENT.md) when contributing in your own capacity.
- Use the [Corporate Contributor Agreement](CORPORATE_CONTRIBUTOR_AGREEMENT.md) when contributions are made by employees, contractors, or representatives on behalf of an organization.
- If an employer, university, client, sponsor, or other party may own or control the work, obtain its written authorization before contributing.

## How to complete the agreement

1. Download or print the applicable agreement from the default branch.
2. Complete all identification, GitHub-account, and signature fields.
3. Sign electronically or by hand.
4. Send the complete signed agreement to **alex@botshare.ai** with subject:
   `OpenAMRobot Contributor Agreement — [name / organization]`.
5. Botshare LTD records acceptance privately and confirms the GitHub accounts covered.
6. Open or update the pull request only after confirmation.

Signed agreements and identity records must not be committed to a public repository.

## Contribution acceptance

DCO and contributor-agreement requirements are cumulative. A contribution is accepted only when an authorized maintainer merges it into an official OpenAMRobot repository or Botshare LTD confirms acceptance in writing.

Agreement status may be recorded in a private register or an approved automated check. A pull request must not be merged while the requirement is unsatisfied.

## Changes to agreement terms

The agreement version accepted by the contributor governs contributions covered by it. Material amendments require new acceptance; changing a public Markdown file does not silently replace an executed agreement.
