# OpenAMRobot

An open, modular embodied AI robotics ecosystem: an autonomous mobile base, an upper body for manipulation, and the ROS 2 software, firmware, and hardware designs that make them one robot.

> **Status:** Active

![OpenAMRobot ecosystem](https://raw.githubusercontent.com/openAMRobot/openamr/main/docs/hardware/pictures/OpenAMRobot_ecosystem.png)
