# OpenAMRobot Maintainers

## Purpose

This document defines maintainer responsibilities within the OpenAMRobot ecosystem.

Maintainers help ensure technical quality, governance consistency, and long-term sustainability.

---

# Organization Maintainers

Organization maintainers are responsible for:

- governance coordination
- repository oversight
- branding protection
- infrastructure management
- organization-wide standards
- release coordination
- community moderation when necessary

Organization maintainers may manage multiple repositories.

---

# Repository Maintainers

Each repository may define repository-specific maintainers.

Repository maintainers are responsible for:

- reviewing pull requests
- managing issues
- maintaining documentation
- improving repository quality
- enforcing repository standards
- supporting contributors
- maintaining repository health

---

# Maintainer Expectations

Maintainers are expected to:

- communicate respectfully
- encourage constructive collaboration
- review contributions fairly
- support contributors
- document important decisions
- maintain technical quality
- consider safety implications where applicable

---

# Decision Making

Maintainers should prefer:

- transparency
- documented discussions
- collaborative decision-making
- technical justification
- community input when practical

---

# Becoming a Maintainer

Potential maintainers may emerge through:

- consistent high-quality contributions
- long-term participation
- technical leadership
- documentation improvements
- community support activities

Maintainer selection is typically based on trust, contribution quality, and ecosystem involvement.

---

# Maintainer Inactivity

Repositories may reassign or expand maintainership when repositories become inactive or unsupported.

---

# Repository Autonomy

Repositories may define additional maintainer rules if they remain compatible with organization governance.

---

# Policy Updates

This document may evolve as the ecosystem grows.
