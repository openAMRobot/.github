# Contributing to OpenAMRobot

## Purpose

Thank you for considering contributing to OpenAMRobot.

OpenAMRobot is an open robotics ecosystem focused on education, research, experimentation, and practical robotics development.

We welcome contributions from developers, roboticists, students, educators, researchers, makers, and industrial collaborators.

---

# Ways to Contribute

You can contribute by:

- reporting bugs
- improving documentation
- submitting code
- improving simulations
- contributing hardware designs
- testing features
- proposing new ideas
- improving tutorials
- helping with discussions
- reviewing pull requests

---

# Contribution Principles

Contributions should support:

- open collaboration
- technical quality
- reproducibility
- safety awareness
- educational value
- maintainability
- respectful communication

---

# Before Contributing

Before submitting a contribution, please check:

- existing issues
- open pull requests
- repository documentation
- project roadmap if available

For large changes, open an issue or discussion first.

---

# Pull Request Guidelines

Pull requests should:

- describe the problem being solved
- explain the proposed solution
- include testing information where applicable
- update documentation if needed
- avoid unrelated changes
- follow the repository structure and style

---

# Commit Sign-Off

OpenAMRobot may use Developer Certificate of Origin (DCO) sign-off.

You can sign commits using:

```bash
git commit -s
```

This adds:

```text
Signed-off-by: Your Name <your@email.com>
```

---

# Safety

OpenAMRobot projects may involve robotics, electronics, motors, batteries, autonomous systems, and AI components.

Contributors should consider safety implications when submitting changes.

No contribution should be assumed safe for real-world deployment without independent validation.
